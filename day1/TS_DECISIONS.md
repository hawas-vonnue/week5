- If strict is false and we are enabling strict flags individually the enabled flags are:

## Enabled option

- noImplicitAny: to show error on every implicit any
- strictNullChecks: to show error on every null and undefined
- strictFunctionTypes: to check function parameters more correctly
- noUnchekedIndexedAccess ():access to not existing return undefined

` you have to enable noUnchekedIndexedAccess separately even with strict flag true`
